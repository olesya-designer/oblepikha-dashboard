# ЖК «Облепиха»: Vue + D3 dashboard

Учебный интерактивный дашборд для задания по алгоритму Δλ.

## Что реализовано

- частица данных = одна квартира;
- матрица всех квартир по корпусам и этажам: продана / остаётся в продаже;
- недельная динамика выручки и числа сделок;
- сравнение менеджеров по выручке, числу сделок, скидкам и сроку сделки;
- анализ ликвидности по корпусу, комнатности, виду, этажу, площади, цене и планировке;
- общие фильтры и клики по графикам;
- карточка выбранной квартиры;
- автоматические текстовые наблюдения и предупреждение о неполном августе;
- исходный CSV лежит в `public/data/apartments.csv`.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://localhost:5173`).

## Сборка для публикации

```bash
npm run build
```

Папку `dist/` можно разместить на GitHub Pages, Netlify, Vercel или любом статическом хостинге. В `vite.config.js` установлен относительный `base`, поэтому сборка не привязана к корню домена.

## Как снимать скринкаст 3–5 минут

1. Сначала покажите общие KPI и недельную динамику.
2. В матрице объясните, что каждый квадрат — квартира, а не агрегат.
3. Нажмите на менеджера и сравните число сделок / выручку / скидки.
4. В «Что продаётся лучше» переключите `Корпус`, `Вид из окна`, `Этаж`.
5. Закончите тремя выводами из блока внизу страницы.

## Ограничение данных

Для непроданных квартир нет закреплённого менеджера и даты обращения. Поэтому датасет позволяет сравнить менеджеров по уже закрытым сделкам, но не позволяет корректно считать конверсию менеджера из всех обращений в покупку.
