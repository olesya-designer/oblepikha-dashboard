# ЖК «Облепиха» — Vue + D3

Одноэкранный интерактивный дашборд продаж квартир. Оптимизирован под Full HD (1920×1080).

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Исходный датасет лежит в `public/data/apartments.csv`.

### Что считается «окупаемостью» корпуса

Линия под каждым корпусом показывает долю уже полученной выручки от полной прайсовой стоимости всех квартир корпуса:

`выручка по проданным / сумма прайсовых цен всех квартир корпуса`.

Это не бухгалтерский ROI: в датасете нет себестоимости строительства.

## Последняя дизайн-правка

Вёрстка приведена к принципу «внутреннего и внешнего»: расстояния внутри смысловых модулей меньше, чем расстояния между самостоятельными модулями. Интерфейс стал более типографичным и плоским: белый фон, чёрные конструктивные линии, минимум декоративных плашек, один уровень акцентов. На всех основных интерактивных графиках восстановлены hover-подсказки.
